# gating_metrics open benchmark — external hold-out of the gating measurement specification

This directory is an **open benchmark** for testing the state-gated co-expression
measurement specification on subject-level data, with the authors' own four-cohort
external hold-out included as the seeded reference set.

## Ground truth (stated up front, honestly)

The authors' registered prediction — **negative reference-stratum coupling in
acute-inflammation whole-blood bulk cohorts** — was **NOT externally confirmed**
on the four seeded cohorts (reference strata 2/4 direction-negative; pooled
fixed-effect r = +0.004, n = 127; the frozen ≥80% and pooled-above-MDE criteria
both failed). The prediction and its frozen verdict logic are public (OSF
registration DOI 10.17605/OSF.IO/4TZH9; value-blind pre-registration preceded any
contact with these datasets). The acute-inflamed strata of the same cohorts
couple negatively (e.g. septic shock −0.38, p ≈ 2×10⁻⁷), which is a post-hoc
observation labelled as such in the companion manuscript.

The benchmark therefore ships with a **negative seeded verdict on purpose**:
its value is the protocol, not a positive headline. Any group can (a) recompute
this verdict end-to-end, and (b) add cohorts under the identical frozen protocol
so the field accumulates evidence under one metric dictionary.

## Contents

| Item | Description |
|---|---|
| `data/G1_<ACCESSION>_per_sample.csv` | Subject-level derived data for the four hold-out cohorts (GSE66099 paediatric sepsis, GSE40012 pneumonia/SIRS, GSE57065 septic shock, GSE37069 burns): columns `gsm, title, stratum, KAT2A_Z, module_Z, AGI`. Derived from public GEO series matrices (accessions citable); no redistribution of raw matrices is needed. |
| `run_benchmark.py` | Standalone recomputation of the frozen verdicts PG1-1..PG1-4 (stratum Spearman, Fisher-Z fixed-effect and DerSimonian–Laird pooling, closed-form MDE at 80% power). Dependencies: numpy, scipy, pandas. |
| `benchmark_results.csv` | Regenerated by the script on each run (the shipped copy is the authors' run). |

## The frozen protocol (summary)

1. Metric dictionary (identical to the `gating_metrics` package and the OSF
   registration): highest-variance probe per gene, Z across the full cohort,
   module = mean Z over {NLRP3, NLRC4, PYCARD, CASP1, IL1B}, coupling =
   Spearman(KAT2A_Z, module_Z) within stratum, reference stratum = healthy /
   un-inflamed baseline (`control_REF`).
2. Verdicts: PG1-1 ≥80% of cohorts reference-negative; PG1-3 pooled fixed-effect
   r significantly negative (one-sided p<0.05) with |r| ≥ closed-form MDE at the
   pooled n; the specification is "externally validated" only if PG1-1 AND PG1-3.
3. Power planning: |r| = 0.35 needs n ≈ 62, |r| = 0.30 needs n ≈ 84 at 80% power
   (two-sided α = 0.05) — use the `gating_metrics.power` routines.

## Adding your cohort

Build a `G1_<ACCESSION>_per_sample.csv` with the same columns (the `gating_metrics`
package ships the routines that construct KAT2A_Z/module_Z under the frozen
dictionary), drop it in `data/`, rerun `python run_benchmark.py`. Pre-register
your prediction before looking at the coupling values — that is the point of the
protocol.
